# MediLab Nexus Screenshot Checklist

## Purpose

Use this checklist to capture production-ready screenshots and drop them into the manuals later.

## Capture Rules

- Use real UI labels but avoid exposing real patient-identifying data.
- Prefer test or anonymized records.
- Use consistent browser zoom and window size.
- Capture clean screens without unrelated pop-ups.
- Show the active page header and the key action area.

## Core Screenshots

- Sign-in screen
- Register first admin flow
- Dashboard
- Patients registration form
- Patient Records search and history view
- Lab Reports editor with template import actions

- Printable report preview
- Expenses page
- Services page with turnaround days, hours, and minutes
- Operations Report summary
