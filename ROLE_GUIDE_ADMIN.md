# MediLab Nexus Administrator Guide

## Main Goal

Administrators maintain user access, system safety, facility settings, backups, and overall operational control.

## Main Pages

- Dashboard
- All operational pages as assigned
- Audit Logs
- User Management
- Alerts
- Settings

> Screenshot placeholder: admin portal with system pages.

## Initial Responsibilities

1. Create staff accounts.
2. Assign the correct role to each user.
3. Confirm facility profile details.
4. Load or review services and pricing.
5. Confirm backup and dispatch procedures.

## User Administration

Use User Management to:

- Add users
- Recover PINs
- Unlock accounts
- Activate or deactivate users
- Review role assignments

## Settings and System Operations

Use Settings to:

- Maintain the facility name, contacts, logo, and footer message
- Adjust printable font size when needed
- Create, export, import, and restore backups
- Run dispatch when integration or notification processing must be triggered manually

## Audit and Oversight

Use Audit Logs and Alerts to:

- Review important actions
- Confirm who changed what
- Monitor internal bell usage
- Review queued or failed notifications

## Common Mistakes to Avoid

- Giving users broader access than necessary.
- Leaving temporary or recovered PINs unchanged.
- Failing to export backups to a safe external location.
- Ignoring repeated lockouts, failed notifications, or audit anomalies.

## Escalate When

- Backups fail or cannot be restored.
- Multiple users lose access.
- Notifications or dispatch controls show abnormal behavior.
- Audit activity suggests misuse or a compliance problem.
